# 🏥 Hospital Management System (MERN Stack)

## 📌 Project Description
A full-stack Hospital Management System built using the MERN stack.  
It supports multiple roles including Admin, Doctor, Patient, and Receptionist.

---

## ✨ Features

### 👤 Patient
- Book appointments
- View appointment history
- Check payment status

### 👨‍⚕️ Doctor
- View assigned appointments

### 👨‍💼 Admin
- Add/manage doctors
- View system data

### 🧾 Receptionist
- Book appointments for offline patients

---

## 🛠 Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB
- State Management: Redux Toolkit
- Authentication: JWT
